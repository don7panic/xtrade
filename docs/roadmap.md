# XTrade Roadmap

下面将建议拆成产品路线图（roadmap），按功能点拆分 milestone，并给出每项的验证指标与验收标准。

## M0：定位与体验对齐（2周）

功能点：
- 产品定位明确化
- CLI/TUI 命令统一
- 文档与实际功能一致
- 首屏 onboarding 改进

验证指标：
- 新用户完成“启动-订阅-查看-退出”的成功率 ≥ 90%
- 文档与 CLI/TUI 命令一致性问题数 = 0（无命令缺失/错误）

验收标准：
- `README` + `user_guide` 与实际 CLI/TUI 功能一致
- TUI 欢迎页可直接引导用户完成核心路径（订阅/切换/退出）
- 文档中列出的命令在程序内可实际调用且有反馈

## M0.5：Paper Trading 模拟交易（1-1.5周）

功能点：
- `/buy <symbol> <qty>` 与 `/sell <symbol> <qty>` 命令
- `/portfolio` 命令显示持仓与浮动盈亏
- 内存撮合引擎：Market Order 立即以当前价格成交
- TUI 新增 "Portfolio" 面板（持仓、成本、当前价格、PnL）
- 订单历史查看（内存）

验证指标：
- 下单后持仓更新延迟 P95 < 100ms
- 持仓盈亏随行情实时刷新（与 ticker 同步）
- 命令解析成功率 100%（合法输入）

验收标准：
- 支持买入/卖出模拟订单（Market Order）
- TUI Portfolio 面板可查看：symbol、数量、成本价、当前价、浮动盈亏
- `/portfolio` 命令在非 TUI 模式下输出格式化持仓列表
- 重启后持仓清空（内存模式，不持久化）

## M1：告警系统增强（3周）

功能点：
- 告警持久化
- 告警历史
- 通知渠道（Webhook/Telegram/Email）
- 复杂条件（涨跌幅/区间/时间窗）

验证指标：
- 告警触发延迟 P95 < 1s（网络正常）
- 触发后通知成功率 ≥ 99%
- 告警重复触发误报率 < 1%

验收标准：
- 重启后告警仍可恢复且状态不丢失
- 可查看告警历史与触发记录（带时间、条件、价格）
- 支持至少 1 个外部通知渠道并可配置开关

## M2：数据持久化与回放（3–4周）

功能点：
- SQLite 存储行情快照/订单簿摘要/K线
- 导出与回放模式
- 数据窗口管理

验证指标：
- 长时间运行（24h）数据丢失率 = 0
- 数据写入对实时渲染影响 < 5% CPU
- 回放模式与实时渲染一致性 ≥ 99%

验收标准：
- 支持配置存储开关、数据保留策略（时间或容量）
- 可导出指定时间段数据（CSV/JSON）
- UI 可切换“实时/回放”，并能定位至指定时间点

## M3：观察与使用效率提升（2–3周）

功能点：
- watchlist
- 符号搜索/过滤/排序
- 布局记忆
- 面板定制
- 键盘快捷增强

验证指标：
- 找到并订阅目标 symbol 的平均操作步数 ≤ 3
- 布局复用率 ≥ 70%（用户重开仍沿用）

验收标准：
- 支持搜索与快速添加/移除 symbols
- 支持保存/加载布局（多 workspace 或 profile）
- 提供面板隐藏/排序/缩放等控制

## M4：交易能力 MVP（4–6周）

功能点：
- API Key 管理（加密存储）
- Paper Trading
- 基础下单/撤单
- 持仓与 PnL
- 基础风控（限价/仓位上限）

验证指标：
- 下单成功率 ≥ 99%（测试环境）
- 订单状态更新延迟 P95 < 1s
- 关键风控触发覆盖率 100%

验收标准：
- API Key 安全存储与读取，支持 Testnet
- Paper trading 可独立运行并支持持仓/盈亏查看
- 基础风控可配置并可阻止违规下单

## M5：多交易所与自动化策略（6+周）

功能点：
- 多交易所适配层
- 策略插件化（DCA/Grid）
- 回测框架初版
- 统一行情聚合

验证指标：
- 至少 2 个交易所（Binance + 1 个）数据接入可用性 ≥ 99%
- 策略回测结果与历史数据一致性 ≥ 99%

验收标准：
- 新交易所接入只需实现适配层接口
- 策略可在回测与实时运行间切换
- 指标与日志可归一展示
